# FileLens

FileLens 是一个本地优先的重复文件整理工具：多目录扫描、BLAKE3 完整内容哈希确认精确重复、感知指纹给出相似候选、可恢复的应用回收站，所有处理仅在人工确认后执行。桌面端基于 Tauri 2 + React 19，核心逻辑是独立的 Rust 库（含 CLI）。

> 📖 使用说明见 [docs/MANUAL.md](docs/MANUAL.md)，项目进展报告见 [docs/REPORT.md](docs/REPORT.md)。

## 功能

- **扫描与索引**：增量扫描（按大小+修改时间跳过未变文件）、并行哈希（多线程管线）、进度百分比/速度/预计剩余时间/当前处理路径、可取消、失效目录自动跳过、逐文件失败清单（最近 20 条）、外部删除的文件在下次扫描标记缺席；**重命名/移动识别**（NTFS 文件引用号 / POSIX 设备+inode，继承哈希与指纹不重算）；可选**实时监控**（目录变化静置三秒自动增量扫描，新增根目录保存后自动接管，扫描进行时后台校验自动让核）；外部消失且 90 天未回归、从未参与操作的索引行扫描后自动清理；可选 USN 快扫（Windows 管理员）。大文件全量哈希阶段实时显示文件名与累计哈希字节。自定义排除规则与最小文件大小（设置页 / CLI）。>16 MB 文件两级哈希：先比前 64 KB 指纹，同桶才计算全量。启动时可用已保存目录自动增量扫描（设置页可关）。
- **检测能力**：精确重复（BLAKE3 + 大小，可自动处理）；照片检测分两类可选查看——**重复照片**（双指纹完全一致的候选，后台自动**逐像素校验**——结果持久缓存，文件不变不重算；列表只显示确认完全一致的副本，被排除的相似候选数在页头明示）与**相似照片**（pHash 距离阈值可在设置页调整，默认 10/64）；照片两种视图均支持「重复目录」两列对照模式与**合并到一侧**向导：目标文件夹任选（两侧之一 / 其他位置 / 新建路径自动创建），保留条件（**前缀匹配**（默认保留 IMG/Screenshot 等命名，可自定义）、**EXIF 拍摄时间**、**分辨率较高**、**时间较新**、**优先指定目录**）可排序优先级，决定每对照片谁移动到目标、谁回收；相似文档（TXT/MD/CSV/JSON/XML/HTML 的 SimHash ≤8/64，仅人工查看）；音频/视频指纹未接入，界面如实标注。
- **审核与处理**：重复组支持路径筛选/最小大小/排序与总数分页，操作后保留已加载页；智能标记（保留最新/最旧/最短路径）；跨组条件批量——对筛选命中的全部组应用一个保留策略，并一键回收全部已标记副本（受保护路径永不标记）；点击缩略图应用内放大预览（EXIF 方向、磁盘缓存 500MB LRU 自动淘汰）、系统程序打开、文件管理器定位；"标记删除 → 选择回收站、转为硬链接或直接永久删除"的处理语义，硬链接去重保留所有路径并立即释放空间（跨盘副本自动跳过并报告）；可选严格模式在删除前逐字节复核；超 1 GB 文件提示回收站会占用双倍空间；保护路径规则禁止误删，设置页可实时预览规则将保护多少个已索引文件；CSV 报告导出（界面 / CLI）。
- **回收站**：移入前后哈希校验、恢复防覆盖、按批次分组展示与一键整批恢复/整批永久删除（失败逐条跳过并提示）、单个永久删除、一键清空、按保留天数自动过期（默认 30 天，0 关闭，扫描结束时自动清理）、可选**容量提醒上限**（实际占用超过阈值时页面提醒，仅提醒不自动删除）。
- **清理工具**：扫描自动发现**空文件夹**（删除前逐个复核仍为空，跳过扫描根目录与受保护目录，全部留痕）与**零字节文件**（走标准安全链移入回收站），一键批量清理。
- **操作历史**：每次移入/恢复/删除/硬链接全部记录，按时间倒序分页展示。
- **项目自动管理**：首次启动自动创建 SQLite 数据库与回收站目录，零配置；首次使用有 三步引导（添加目录 → 增量扫描 → 审核清理）；界面主题支持 跟随系统 / 日间模式 / 夜间模式（设置页切换，跟随系统实时响应系统深浅色变化）；可自定义位置，重启自动打开上次项目。

## 安全模型

扫描只读取文件。任何删除动作前都要求：文件属于精确重复组、已被人工标记、未被保护规则命中、当前内容与索引哈希一致。移入回收站执行后再次校验哈希；恢复时若原位置已有文件则拒绝执行。

## 构建与安装

桌面端（在仓库根目录）：

```bash
npm install
npm run tauri build            # Linux: deb 等
npm run tauri build -- --bundles nsis --runner cargo-xwin \
  --target x86_64-pc-windows-msvc   # 从 Linux 交叉编译 Windows NSIS 安装包
```

注意：必须通过 `npm run tauri build` 构建——直接 `cargo build` 产出的二进制不包含前端资产。交叉编译 Windows 包需要 `nsis lld llvm`、`rustup target add x86_64-pc-windows-msvc` 和 `cargo install cargo-xwin`。

核心库 CLI（可选）：

```bash
cargo build --release    # 产物为 filelens 命令：init/scan/groups/approve/unapprove/trash/hardlink/strict-verify/restore/status/trash-list/export
cargo test               # 单元测试覆盖扫描→删除→恢复全链路
```

## 数据位置

| 内容 | Linux | Windows |
|---|---|---|
| 数据库/回收站 | `~/.local/share/local.filelens.desktop/` | `%APPDATA%\local.filelens.desktop\` |
| 缩略图缓存 | `~/.cache/local.filelens.desktop/thumbnails/` | `%LOCALAPPDATA%\local.filelens.desktop\thumbnails\` |

数据库结构带自动迁移：老版本库在打开时按迁移框架逐步升级（当前 schema v9：两级哈希的 `quick_hash` 列、硬链接识别的 `dev`/`inode` 列、操作留痕的 `batch_id` 列、照片 pHash 列与 USN 快扫的 `frn` 列、像素校验缓存表 `photo_pair_verdicts`、重命名识别的 `frn`/`dev`+`inode` 索引、EXIF 拍摄时间 `exif_taken` 列、清理工具的 `empty_dirs`/`empty_dir_removals` 表），无需人工干预即可沿用已有索引。schema v5 升级时会清空照片指纹，下次扫描自动重建（每张图片重算一次 dHash + pHash）。
